# Contributing

Thanks for wanting to help. Bug reports, translations and small fixes are all welcome.

## Setup

```bash
npm install
echo "/path/to/a/test/vault" > .vault-path
npm run dev
```

`npm run dev` rebuilds on every change and copies the plugin into the vault
named in `.vault-path`. Use a test vault, not your real one.

## Before opening a pull request

```bash
npm run check
```

This runs the type checker, ESLint with Obsidian's plugin rules, the unit tests
and a production build.

## Layout

- `src/main.ts` only wires things together; each feature lives in `modules/`
  or `integrations/` and can be switched off at runtime.
- `src/i18n/locales/` — one file per language. `en.ts` is the source; the
  compiler refuses any locale that is missing a key or has an extra one.
- `styles/` — one stylesheet per area. The build joins them and adds
  left-to-right overrides generated by `scripts/gen-ltr.mjs`.

## Translations

Write for people who speak the language, not word for word from English. Keep
labels short, follow the language's own punctuation, and never glue a suffix to
a `{placeholder}`: in Arabic and Turkish the ending depends on the word that ends
up there. Plural messages use CLDR categories (`one`, `two`, `few`, `many`,
`other`); add the ones your language needs.

## Comments

Explain why, not what. If a comment repeats the next line, delete it.
